# Responsible AI for Waste Classification

Author: Arun Thomas

University: University of Europe for Applied Sciences (UE)

## Project Overview

This project investigates Responsible AI approaches for waste classification using machine learning and computer vision techniques.

## Research Questions

### RQ1
 How does the trade-off between classification accuracy and computational energy consumption affect the sustainability of AI-based waste sorting systems?

### RQ2
How do lighting conditions, contamination levels, and dataset imbalance influence bias and misclassification in AI-driven waste classification systems??

### RQ3
Can lightweight computer vision models deployed on edge devices provide reliable waste classification while reducing infrastructure cost and energy usage?

### RQ4
How can Explainable AI (XAI) improve transparency and user trust in automated waste classification systems?

### RQ5
Does the environmental benefit gained from AI-assisted recycling outweigh the carbon and hardware costs required to train and deploy the AI system?
